# Imronbek Gaipov - Personal Portfolio

A sleek, responsive personal portfolio website showcasing projects, technical skills, and software development experience.

## ✨ Features
- **Modern & Responsive Design:** Optimized for desktops, tablets, and smartphones.
- **Interactive UI:** Smooth scrolling, active navigation highlighting, and dynamic project showcase.
- **Fast & Lightweight:** Pure HTML5, CSS3, and JavaScript with zero external runtime dependencies.
- **Accessible & Clean Code:** Semantic HTML and well-structured CSS variables.

## 🚀 Getting Started

Simply open `index.html` in any web browser:
```bash
# Clone the repository
git clone https://github.com/imronbekgaipov/imronbek-portfolio.git

# Navigate to project directory
cd imronbek-portfolio

# Open in browser
start index.html
```

## 🛠️ Built With
- **HTML5**
- **CSS3** (Custom Properties, Flexbox, CSS Grid)
- **JavaScript (ES6+)**
